## 🚀 Featured Project: PromiseLane

**[promiselane.in](https://promiselane.in)** — Full-Stack SaaS Platform (Laravel 12 + React 18)

A project governance platform that tracks client requirements, milestones, deliverables, and payments in one shared workspace. Built end-to-end: REST API, JWT auth, service layer architecture, React frontend with Ultra Premium UI, deployed on Railway + Vercel.

**Tech:** Laravel 12 · React 18 · MySQL 8 · JWT · Tailwind CSS · Railway · Vercel

[🔗 Live Site](https://promiselane.in) · [📂 API Repo](https://github.com/Dev-Sooraj-Git/promiselane-api) · [📂 Frontend Repo](https://github.com/Dev-Sooraj-Git/promiselane-frontend)
